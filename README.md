# 🔥 Featured Projects

## 1. 🛡️ Adaptive Application-Layer DDoS Mitigation

**Repository:** [ddosapi](https://github.com/vissakan/ddosapi)

An intelligent **Layer-7 DDoS mitigation system** that uses **Deep Reinforcement Learning** to make adaptive mitigation decisions from real-time application metrics.

Instead of relying only on fixed rules, the system treats DDoS mitigation as a **sequential decision-making problem**. A DRQN agent observes metrics such as request rate, latency, and CPU usage, then selects an appropriate mitigation action based on the current situation.

### What it demonstrates
- Deep Reinforcement Learning with **DRQN**
- Application-layer DDoS mitigation
- Real-time metric-based decisions
- Adaptive actions such as rate limiting, throttling, CAPTCHA, and blocking
- **FastAPI** microservice architecture
- Docker-based deployment
- CI/CD automation

**Tech:** `Python` `DRQN` `FastAPI` `Docker` `GitHub Actions` `Deep Learning`

## 4. 📦 Product Inventory Management System

**Repository:** [Product-Inventory-Management](https://github.com/vissakan/Product-Inventory-Management)

A full-stack **product inventory management system** for managing products, users, roles, and inventory data.

The backend is built with **Spring Boot** and **Spring Security**, the frontend uses **React**, and **PostgreSQL** is used for data storage. The complete application can be run using **Docker Compose**.

### What it demonstrates
- REST API development with Spring Boot
- JWT-based authentication
- Role-based authorization
- Product CRUD operations
- Search, filtering, pagination, and sorting
- PostgreSQL database integration
- Swagger/OpenAPI documentation
- Docker and Docker Compose

**Tech:** `Java` `Spring Boot` `Spring Security` `React` `PostgreSQL` `JWT` `Docker` `Swagger`
